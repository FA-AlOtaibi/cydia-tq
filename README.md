# F11 Football
Native iPhone football game prototype built with Swift + SpriteKit.

## Play
Landscape. Left virtual stick moves the selected blue player. PASS passes toward a teammate, SHOOT kicks toward the attacking direction, RUN gives a sprint burst. Five-minute match, 11v11 AI, keepers, goals, score and timer.

## IPA
GitHub Actions builds an unsigned IPA artifact on every push to master. Install using your preferred signing method / developer certificate.
